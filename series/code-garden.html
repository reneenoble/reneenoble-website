🌱 In the Code Garden

Recordings covering Python, data, web development, cloud and open-source tools.

About the Series

In the Code Garden is a live-coding series I created for people learning Python and related technologies. Each set of episodes grows one practical idea over several sessions, with explanations, experiments and the occasional bug worked out in real time.

Code is available on GitHub. Some later recordings sit outside the original YouTube playlist, so the complete set is embedded below.
