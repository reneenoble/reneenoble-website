Git Yourself a Leg Up for Student Projects

PyCon AU 2023 Git GitHub Education

About This Talk

Git and GitHub are useful for student projects as well as professional development. This talk covers practical ways students can use version control to improve their project work, collaborate and build skills they can use later.

Includes a demo of a Flask web app template designed specifically for student projects.
