Who_Dunnit.xlsx: Teaching Python through Data Investigation

PyCon AU 2025 Python Education Data Science

About This Talk

This talk teaches Python through a murder mystery built in a spreadsheet. Learners investigate data, test ideas and solve the case instead of working through abstract exercises.

The talk is for educators looking for another way to teach programming, and for anyone interested in using a mystery as the structure for a coding project.
